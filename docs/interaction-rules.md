# 공통 인터랙션 규칙 (Living document)

> **번호 교체 (2026-09-12)**: 사용자 요청으로 **1안 ↔ 3안** 을 맞바꿨다. 이 문서의 **2026-09-12 이전 기록에 나오는 "3안" 은 지금의 1안**(현재 방향 + 개인정보 입력 분리, 구현된 16스텝), **"1안" 은 지금의 3안**(Static 중심 + AI Agent 일시 호출, 6스텝)을 가리킨다. 2안은 그대로다. 과거 기록은 당시 번호로 남겨 둔다.


Agent 시나리오 플레이어 전체에 **일괄 적용**되는 모션·인터랙션 규칙. 규칙이 바뀌면 이 문서를 먼저 고치고 코드에 반영한다.
코드 위치를 함께 적어 두어, 문서 ↔ 코드가 어긋나지 않게 한다.

최종 갱신: 2026-09-08 (신청서 시트 플로우 배포)

## 1. Agent 대화 턴의 등장 순서 (확정: S-1 균일 박자)

모든 Agent 응답 턴은 아래 순서로 **하나씩** 나타난다. 순서는 고정, 리듬(간격)만 조정 가능.

| 순서 | 요소 | 시간 (S-1) | 비고 |
|---|---|---|---|
| 1 | 사용자 말풍선 (AiAgentMessage/User) | 등장 후 0.6s 대기 | 발화·버튼 탭 모두 말풍선으로 기록 |
| 2 | 타이틀 영역 (Opening: 상태 텍스트 + AiAgentTitle) | 등장 후 1.75s 유지 (두 번째 턴은 1.0s) | 채팅 시작선(199px)에 앵커 |
| 3 | 타이틀 접힘 | 0.6s (접힘 질감 C-2) | 제자리에서 높이가 닫히고 본문이 올라옴 |
| 4 | 멈춤 | 0.35s | |
| 5 | 본문 텍스트 (AiAgentMessage/Ai) | 등장 후 0.55s 대기 | |
| 6 | 컴포넌트(카드·CTA 칩) 순차 | 0.45s 간격 | 마지막 요소 뒤 0.3s |
| 7 | 팬 | 거리 기반 (아래 §2) | 마지막 요소 하단이 SearchAi 위 30px |

- 타이틀이 없는 턴(예: "다른 요금제 살펴보기")은 2~4를 건너뛰고 1 → 5 → 6 → 7.
- **타이틀(Opening)의 조건 — 확정 2026-09-07**: 타이틀은 고객 요청으로 **내 정보를 조회**해야 하는 턴에만 뜬다 (스텝 4 이용 현황 조회, 스텝 10 위약금 조회). 추가혜택(스텝 7)·할인방법(스텝 8)처럼 단순 전시 턴은 타이틀 없이 **N-2 생각 점**으로 이어진다: 이전 동작 0.9s 뒤 텍스트 자리에 점 3개(한 줄 높이, 1.1s 주기 깜빡임) 등장 → 하단 따라가기 팬 → 0.9s 유지 → 0.18s 페이드아웃 → 같은 자리에 안내 텍스트 → 0.55s → 카드 → 하단 팬. 즉 전시 턴의 순서는 1(있으면 말풍선) → 생각 점 → 5 → 6 → 7.
  - `html[data-disp]` T-0 기존(타이틀) / N-1 바로 이어쓰기 / N-3 카드만은 코드 보존. 비교: https://claude.ai/code/artifact/ce1f98e9-83ba-4868-8bbb-de32e92e6b48
  - 코드: `AgentChat.jsx` → `playTurn()` 앞부분(disp 분기), `Thinking` 컴포넌트, `turnKids()`; `agent.css` → `.thinking`. 스텝 4 후반 "요금제 조회중" 타이틀은 경계 사례로 이번에 유지(미결).
- 등장 질감: 4px 상승 + 페이드 0.7s, ease-in-out(.65,0,.35,1).
- 코드: `src/screens/AgentChat.jsx` → `REVEAL.S1`, `reveal()`, `play5 / play6 / playAlt`. 질감 변수: `src/screens/agent.css` → `--rv-*` (`html[data-reveal]`).
- 시안 기록: S-2 생각하는 리듬 / S-3 빠른 캐스케이드는 코드에 남겨 두되 미사용. 비교 페이지: https://claude.ai/code/artifact/0229b495-f814-4003-ada6-e22faa98e131

## 2. 팬(자동 스크롤) 속도

- **거리 기준 일정 속도**: 320px/s. 최소 0.6s, 최대 3.2s. 이징 ease-in-out sine.
- 이유: 고정 시간(1.1s)으로 긴 구간을 내리면 "확 내려가는" 느낌이 남 (사용자 피드백 2026-09-03).
- 코드: `AgentChat.jsx` → `scrollTo()` (`PAN_SPEED`, `PAN_MIN`, `PAN_MAX`). 바텀시트 내부 리스트 스크롤(B-1 탐색)만 명시 시간 사용.

## 3. 정렬 규칙 (Agent 화면)

- 고정 헤더 = status 59 + appbar 48 + 컨텍스트 헤더(top 124, h 60) → 채팅 시작선 **199px**. 헤더는 완전 불투명(basement + 글로우 복제)이라 올라오는 본문이 헤더 뒤에서 보이지 않는다.
- 타이틀 앵커 뷰: Opening 상단을 199px에 맞춘다.
- 마지막 카드/칩 ↔ SearchAi(353×52, bottom 24) 간격 **30px**. tail spacer 106px.
- 코드: `AgentChat.jsx` → `CHAT_TOP`, `SEARCH_TOP`, `GAP`, `anchorHeader()`, `anchorBottom()`.

### 28-3. 접힐 때 화면이 흐르고 요약 줄이 위로 점프하던 문제 (**수정 · 2026-09-12** · 사용자 "앵커링이 밑에 있다가 5GX가 갑자기 위로 올라가는 게 어색해")

### 28-5. 접힌 것을 다시 겨냥하지 않는다 (**수정 · 배포 2026-09-12** · 사용자 "6번에서 위로 올라갔다가 내려가고 위약금 질문하는 게 어색해")

- 규칙: **접힘이 끝난 자리를 다시 겨냥하지 않는다.** 접힘은 이미 제자리(§28-3·§28-4)에서 끝나므로 뷰는 그대로 두고 멈춤만 준다. 다음 동작(키패드·말풍선)은 `downTo` 계열이라 아래로만 움직인다. 실측 452 → 807 단조 증가, 되감김 0.
